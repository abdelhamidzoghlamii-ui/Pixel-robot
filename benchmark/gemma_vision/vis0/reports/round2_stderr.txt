## Code-change and commit gate

For every code change: (1) Local AI and human define the task; (2) Coder implements
and verifies; (3) Coder automatically invokes the designated independent Reviewer,
without human relay; (4) request includes task, base commit, full candidate diff

verbatim, untruncated and separate from Coder commentary; (8) stop for the human's
explicit commit decision after Local AI discussion; (9) any code change after review
requires new review; (10) commit only approved files and push only with separate
authorization; (11) send DOC DIFFs to Doc Keeper.

“Automatically” means no manual relay between applications. It never hides review
findings, failure, costs/limits, or permission errors. Never use blanket permission
bypasses. Reviewer approval is not authorization to commit.

## AGY headless reviewer

Facts observed on this phone during task HEAT-A (2026-10-13, AGY 1.3.3, Coder
evidence in `/termux-home/review/heat_a/`). Earlier text in this section claimed
otherwise; these observations replace it.

**Models change on Google's side.** `gemini-3.1-pro-high` was withdrawn
server-side between 2026-10-12 21:22 and 2026-10-13 04:27 UTC with the same
binary and account; `--model gemini-3.1-pro-high` now fails as "not recognized".
A settings.json model label naming a withdrawn model is silently remapped (the
log showed "Gemini 3.1 Pro (High)" resolved to "Gemini 3.8 Flash (High)"), so a
session can run on a different model without any error. `agy models` on
2026-10-13 listed: `gemini-3.8-flash-high|medium|low`,
`claude-opus-5-5-low|medium|high`, `claude-sonnet-5-5-low|medium|high`,
`gpt-oss-120b-medium`. The `claude-*` entries are the same model family as a
Claude Code Coder. Before every AGY review: run `agy models`, pass `--model`
explicitly with the exact id from the EXECUTION PROFILE, run the smoke call
below with that id, and confirm the model label in the AGY log afterwards.
A missing model is an INCOMPLETE round; a replacement reviewer needs an owner
decision and a new profile.

Smoke call (substitute the profile's model id):
```bash
agy -p 'Reply exactly: REVIEW_SMOKE_PASS. Do not inspect files, run commands, call tools, or make changes.' \
  --model "$AGY_MODEL" --output-format json --sandbox --print-timeout 2m
```
It must return `{"status":"SUCCESS","response":"REVIEW_SMOKE_PASS\n"}`.
Review invocation, run from inside the isolated copy:
```bash
agy -p "$REVIEW_REQUEST" --model "$AGY_MODEL" \
  --output-format json --sandbox --print-timeout 10m
```
`$REVIEW_REQUEST` (keep it under 100 KB; put the diff, context and check output
as files in the copy and name them) contains the frozen task, base, no-mutation
rules and a final-review request. Preserve stdout as the complete JSON review
and stderr as separate diagnostics. It is a direct Coder action, not an
executable helper.

**The shared settings are not neutral.** `/root/.gemini/antigravity-cli/settings.json`
(observed 2026-10-13) has `artifactReviewPolicy: always-proceed`,
`allowNonWorkspaceAccess: true`, 36 command allow entries (including
`git commit` and `git push origin main`), empty deny and ask lists, and trusted
workspaces `/termux-home/robot`, `/termux-home/laya-test` and `/root`. It was
rewritten at 2026-10-13 04:58:50 UTC by a process that is not identified.
Allow-listed commands run without asking, also in headless mode.

**Commands in headless mode.** Nobody can approve a prompt in headless mode, so
commands that are not allow-listed do not run. Allow-listed commands do run.
**`--sandbox` does not confine them in proot:** in HEAT-A round 3 the reviewer
reported that the terminal sandbox failed (`fork/exec /root/.local/bin/agy:
operation not permitted`) and that the allow-listed commands were re-run with the
sandbox bypassed; nobody approved anything and `--dangerously-skip-permissions`
was not used. The commands did run: their results matched the Coder's, and in
round 2 they left `.pyc` files in the copy. Headless workspace reads
and writes are also auto-allowed by default (official
[headless](https://antigravity.google/docs/cli/headless/) documentation). A
prompt is therefore never a read-only boundary. Never use
`--dangerously-skip-permissions`.

**Procedure that produced a valid review (HEAT-A round 3, owner-approved):**
1. No other AGY session runs while the overlay below is in place.
2. Back up settings.json and record its SHA-256.
3. Temporary overlay: allow entries for exactly the check commands the reviewer
   must rerun (absolute interpreter path), and `"deny": ["command(git*)"]`.
   No wildcard interpreter allow. Deny precedes ask precedes allow
   ([permissions](https://antigravity.google/docs/cli/permissions/)).
4. Isolated copy: tracked files plus new candidate files, without `.git` and
   ignored files; check free space first.
5. Before and after the call: SHA-256 of every file in the copy and in the live
   tree (except `.git/`), `git rev-parse HEAD origin/main`,
   `git ls-remote origin refs/heads/main`, `git stash list`,
   `git status --porcelain=v1 -uall --ignored`, and the settings.json hash.
   Any difference makes the round INVALID.
6. Checks the reviewer runs must write nothing: `python -B -m py_compile` still
   writes `.pyc` files; use `compile()` instead.
7. The reviewer states each file's line count and quotes the exact code line for
   every file:line it cites. The Coder verifies every citation against the copy;
   a citation to a missing or different line makes the round INVALID (HEAT-A
   round 2 cited lines past the end of a file).
8. Restore settings.json from the backup right after the call and verify the hash.

A true read-only reviewer still needs a dedicated AGY configuration or OS
account, not the shared configuration. Its `settings.json` would use strict,
sandboxed permissions and deny mutation tools:
```json
{"enableTerminalSandbox":true,"toolPermission":"strict","permissions":{"deny":["write_file(*)","command(*)","mcp(*)","execute_url(*)"]}}
```
This dedicated policy is not provisioned or tested; do not add it to the shared
settings, because it would block other AGY role sessions. Authentication, quota,
model, or permission failures mean incomplete review, never a pass. Sources:
[permissions](https://antigravity.google/docs/cli/permissions/) and
[sandbox](https://antigravity.google/docs/cli/sandbox/).

**Per-cycle flow** (`main.py: Robot.run_cycle`):
```
RobotCam frame (640×480, 1/s, fail-closed reader) → YOLO yolo11s (320, 640 every 5 s or in person search; 2 threads on MID cores 4–5) → navigate_rules (pure Python, instant; shaped by the picker's mode) → person-stop (area bucket) → execute move
Picker (background worker, BIG cpus 6–7; ACTIVE only, never at Android status SEVERE): RelateAnything M2 on the latest 640 frame → Gemma letter scoring of EXPLORE / APPROACH / GREET / LOOK → mode for the next cycles (events, min gap 5 s; heartbeat 20 s). In the motors-off run it always chose EXPLORE (#139, #140).
```

| Layer | Handles | Cost |
|---|---|---|
| YOLO yolo11s (320/640 policy, both sessions resident; yolo11m kept for rollback) | object/person detection, position, coarse distance | every cycle |
| RobotCam app (Camera2 foreground service) | 640×480 frames, 1/s (#136); missing/old/repeated frame → STOP | continuous while a mission runs |
| Python `navigate_rules` | obstacle stop, person approach (APPROACH mode or `--no-picker`), room signature logging | every cycle, 0ms |
| Person-stop (#79, #138) | any person in bucket `close`/`very close` turns a forward move into HOLD (stop for the cycle; the mission continues) | every cycle |
| Gemma 4 E2B (Q4_0, default since 2026-09-26) | mission picker (letter scoring of the offered modes, #138) and voice→intent; never a motor command | picker: median 2.8 s per pick in the motors-off run (#139) |
| RelateAnything M2 (relsgg-vits16, fp32, `relate.py`) | object-relation text for the picker (layout L2, #131, #138) | before each pick; median 0.73 s in the motors-off run (#139) |
| Whisper.cpp (base) | 5s voice capture → text | on demand |
| Gemma `PARSE_SYS` | voice text → JSON action array | on demand |
| `termux-tts-speak` | speech output | on demand |

The high-level selector (#109) is wired into the mission loop as the picker
(#138, `2ce2b3b`), on by default; `--no-picker` keeps the old rules. In the
motors-off run it chose EXPLORE every time and cut the ACTIVE share to 0.48
(#139); desk tests found no prompt or model that qualifies (#140). Owner
direction (#140): Gemma becomes the robot's "mind", called at events (talk,
describe, remember, plan); Python keeps every move. The mind is not designed
yet; whether `--no-picker` becomes the default is open. Fine-tuning (Laya, Von
or Gemma) is deferred to a later robot version. One resident Gemma for talk and
selection was decided in #125.
The current repo describes a mecanum prototype; the phone-mounted RC car with
2D LiDAR is a proposed redesign.

**Vision** (`detect_person.py`)
```
yolo11s_320.onnx + yolo11s_640.onnx (stock COCO) · CONF 0.35 · IOU 0.45
SizePolicy: drive = 320 every frame + one 640 every 5 s; person_search = 640 until person box ≥ 1/3 frame height
```

## Thermal governance

VIRTUAL-SKIN-CPU-GPU is the reported HAL CPU-throttling signal (first trip
37.0 °C); BIG/zone9 is not its HAL governor (DECISIONS #90). `run_mission` uses `heat_control.py`
(#135): Android status and VIRTUAL-SKIN every 5 s, adaptive 37/35 °C camera-off
pauses and the #127 stops; validated in one motors-off dry run, not with motors live. The dated device
thresholds, formula, zone map, throttle checks, and evidence limitations are
preserved in [PROTOTYPE_EVIDENCE.md](PROTOTYPE_EVIDENCE.md).

Camera paths (3-min blocks, on battery): RobotCam 2.3 W vs
`termux-camera-photo` 3.3 W over 0.7 W idle (DECISIONS #122; its zone9 rise
rates are not trusted, #126). Measured (#126, room 22 °C): under RobotCam 2/s +
640 every frame + continuous Gemma, the CPU is first capped within 2 s while the
skin is about 32 °C; from 6 min the phone holds 3.68–4.24 W; status LIGHT at
78 s, MODERATE at 10.7 min, SEVERE (skin 45 °C) at 18.3 min. Co-residency
(#125): mix 4.1–4.3 W, 640-only 5.8–6.3 W. Heat rules (#127) and the #129 pauses
are implemented with the adaptive 37/35 °C schedule (#135); the #129 torch is not. Every heat reading in the repo
is labelled in `benchmark/thermal_char/HEAT_EVIDENCE.md`. Power map, power split,
duty-cycle and camera-power measurements (#128) and the owner's heat-pause design
(#129; implemented in #135 except the torch) are archived in `benchmark/power_map/`,
`benchmark/duty_cycle/` and `benchmark/camera_power/`.

# CLAUDE.md

Behavioral guidelines to reduce common LLM coding mistakes. Merge with project-specific instructions as needed.

**Tradeoff:** These guidelines bias toward caution over speed. For trivial tasks, use judgment.

## 1. Think Before Coding

**Don't assume. Don't hide confusion. Surface tradeoffs.**

Before implementing:
- State your assumptions explicitly. If uncertain, ask.
- If multiple interpretations exist, present them - don't pick silently.
- If a simpler approach exists, say so. Push back when warranted.
- If something is unclear, stop. Name what's confusing. Ask.

## 2. Simplicity First

**Minimum code that solves the problem. Nothing speculative.**

- No features beyond what was asked.
- No abstractions for single-use code.
- No "flexibility" or "configurability" that wasn't requested.
- No error handling for impossible scenarios.
- If you write 200 lines and it could be 50, rewrite it.

Ask yourself: "Would a senior engineer say this is overcomplicated?" If yes, simplify.

## 3. Surgical Changes

**Touch only what you must. Clean up only your own mess.**

When editing existing code:
- Don't "improve" adjacent code, comments, or formatting.
- Don't refactor things that aren't broken.
- Match existing style, even if you'd do it differently.
- If you notice unrelated dead code, mention it - don't delete it.

When your changes create orphans:
- Remove imports/variables/functions that YOUR changes made unused.
- Don't remove pre-existing dead code unless asked.

The test: Every changed line should trace directly to the user's request.

## 4. Goal-Driven Execution

**Define success criteria. Loop until verified.**

Transform tasks into verifiable goals:
- "Add validation" → "Write tests for invalid inputs, then make them pass"
- "Fix the bug" → "Write a test that reproduces it, then make it pass"
- "Refactor X" → "Ensure tests pass before and after"

For multi-step tasks, state a brief plan:
```
1. [Step] → verify: [check]
2. [Step] → verify: [check]
3. [Step] → verify: [check]
```

Strong success criteria let you loop independently. Weak criteria ("make it work") require constant clarification.

## 5. Context Discipline

**Context is a budget. Spend it on reasoning, not on re-reading.**

- Never re-read a full file already open in this session. Reference what
  you already have. If you need one function, quote that function - not
  the file.
- Summarize benchmark results as a single row, not raw logs.
  Good: `E2B Q4_K_M | 4 threads | 11-12 tok/s | thermal=PENDING`
  Bad: pasting 15 lines of per-cycle output.
- Don't paste full stack traces. Extract only the failing line and the
  exception type. The other 20 frames are noise.
  Good: `stereo_depth.py:627 ZeroDivisionError - height_px was 0`
  Bad: the entire traceback.
- Terminal output: paste the result, not the scrollback. Server boot logs,
  model metadata dumps, and `cmake` output are almost never the signal.
- When a command produces >20 lines, pipe it: `| tail -5`, `| grep ERROR`,
  or write a summary block at the end of the script.

   282	def classify_tokenized_marker(marker_str, tokens):
   283	    """Determine whether the turn marker tag in marker_str tokenized as ONE special token or several pieces."""
   284	    tag = marker_str[:marker_str.index('>') + 1] if '>' in marker_str else marker_str
   285	    pieces = [t.get('piece') for t in tokens]
   286	    tag_is_single = bool(tokens) and pieces[0] == tag
   287	    whole_is_single = len(tokens) == 1 and tag_is_single
   288	    if whole_is_single:
   289	        summary = 'ONE special token'
   290	    elif tag_is_single:
   291	        summary = f'ONE special token ({tag}) + role token ({len(tokens)} tokens total)'
   292	    else:
   293	        summary = f'several plain-text pieces ({len(tokens)} pieces)'
   294	    return {
   295	        'input': marker_str,
   296	        'tag': tag,
   297	        'token_count': len(tokens),
   298	        'tokens': tokens,
   299	        'pieces': pieces,
   300	        'tag_is_single_special_token': tag_is_single,
   301	        'whole_input_is_single_token': whole_is_single,
   302	        'classification': summary,
   303	    }

   306	def evaluate_template_verdict(chat_template, tokenize_results, rendered_hi):
   307	    """Return CONFIRMED / REFUTED / UNCLEAR that Gemma 3 markers are wrong for this model."""
   308	    by_input = {r['input']: r for r in tokenize_results}
   309	    gemma3_plain = (
   310	        not by_input['<start_of_turn>user']['tag_is_single_special_token']
   311	        and not by_input['<end_of_turn>']['tag_is_single_special_token']
   312	    )
   313	    gemma4_special = (
   314	        by_input['<|turn>user']['tag_is_single_special_token']
   315	        and by_input['<turn|>']['tag_is_single_special_token']
   316	        and by_input['<|turn>model']['tag_is_single_special_token']
   317	    )
   318	    template_uses_gemma4 = (
   319	        '<|turn>' in str(chat_template)
   320	        and '<turn|>' in str(chat_template)
   321	        and '<start_of_turn>' not in str(chat_template)
   322	        and '<end_of_turn>' not in str(chat_template)
   323	    )
   324	    rendered_uses_gemma4 = '<|turn>user\nHi<turn|>\n' in str(rendered_hi) and '<|turn>model\n' in str(rendered_hi)
   325	    if gemma3_plain and gemma4_special and template_uses_gemma4 and rendered_uses_gemma4:
   326	        return 'CONFIRMED'
   327	    if (
   328	        by_input['<start_of_turn>user']['tag_is_single_special_token']
   329	        and by_input['<end_of_turn>']['tag_is_single_special_token']
   330	    ):
   331	        return 'REFUTED'
   332	    return 'UNCLEAR'

   350	def load_target_frames(
   351	    results_json_path=M2Q1_RESULTS_JSON,
   352	    frames_dir=M2Q1_FRAMES_DIR,
   353	    limit=None,
   354	    stems=FRAME_STEMS,
   355	):
   356	    """Load the target frames, enforcing exact frame identity and 640 px JPEG resolution."""
   357	    with open(results_json_path, 'r', encoding='utf-8') as f:
   358	        m2q1 = json.load(f)
   359	    by_stem = {}
   360	    for rec in m2q1.get('photos', []):
   361	        frame_name = Path(rec['frame_file']).name
   362	        stem = frame_name[:-4] if frame_name.endswith('.jpg') else frame_name
   363	        by_stem[stem] = rec
   364	
   365	    selected_stems = stems[:limit] if limit is not None else stems
   366	    items = []
   367	    for wanted in selected_stems:
   368	        if wanted not in by_stem:
   369	            raise RuntimeError(f'Required frame {wanted!r} not found in {results_json_path}')
   370	        matched_stem = wanted
   371	        rec = by_stem[matched_stem]
   372	        frame_path = Path(frames_dir) / f'{matched_stem}.jpg'
   373	        if not frame_path.is_file():
   374	            raise RuntimeError(f'Frame file missing: {frame_path}')
   375	        yolo_lines, user_text, old_prompt = extract_yolo_lines_from_m2q1_record(rec)
   376	        frame_bytes = frame_path.read_bytes()
   377	        with Image.open(io.BytesIO(frame_bytes)) as img_check:
   378	            actual_size = [int(img_check.width), int(img_check.height)]
   379	        if max(actual_size) != 640 or min(actual_size) <= 0:
   380	            raise RuntimeError(
   381	                f'Frame {frame_path} has dimensions {actual_size}, expected 640 px longest edge'
   382	            )
   383	        recorded_size = rec.get('frame_size')
   384	        if recorded_size is not None and [int(recorded_size[0]), int(recorded_size[1])] != actual_size:
   385	            raise RuntimeError(
   386	                f'Frame size mismatch for {matched_stem}: results.json has {recorded_size}, JPEG is {actual_size}'
   387	            )
   388	        frame_sha = hashlib.sha256(frame_bytes).hexdigest()
   389	        items.append({
   390	            'requested_stem': wanted,
   391	            'frame_stem': matched_stem,
   392	            'match_note': 'exact match',
   393	            'photo': rec['photo'],
   394	            'frame_path': str(frame_path),
   395	            'frame_sha256': frame_sha,
   396	            'frame_bytes': len(frame_bytes),
   397	            'frame_size': actual_size,

   399	            'yolo_lines': yolo_lines,
   400	            'user_text': user_text,
   401	            'old_prompt': old_prompt,
   402	            'm2q1_replies': rec.get('replies'),
   403	        })
   404	    return items

   415	def parse_server_log_delta(log_delta):
   416	    """Extract logged image token counts and image-encode time (if printed) from a server log slice."""
   417	    batch_tokens = [
   418	        int(m) for m in re.findall(r'decoding image batch \d+/\d+, n_tokens_batch = (\d+)', log_delta)
   419	    ]
   420	    enc_batch_tokens = [
   421	        int(m) for m in re.findall(r'encoding batch with \d+ entries and total (\d+) tokens', log_delta)
   422	    ]
   423	    sampler_tokens = [
   424	        int(tot) - int(txt)
   425	        for txt, tot in re.findall(r'init sampler, took [0-9.]+ ms, tokens: text = (\d+), total = (\d+)', log_delta)
   426	        if int(tot) > int(txt)
   427	    ]
   428	    if batch_tokens:
   429	        image_tokens = sum(batch_tokens)
   430	    elif enc_batch_tokens:
   431	        image_tokens = enc_batch_tokens[-1]
   432	    elif sampler_tokens:
   433	        image_tokens = sampler_tokens[-1]
   434	    else:
   435	        image_tokens = None
   436	
   437	    encode_ms = None
   438	    for pat in (
   439	        r'image_encode[^0-9\n]*([0-9]+(?:\.[0-9]+)?)\s*ms',
   440	        r'slice\s+encoded\s+in\s+([0-9]+(?:\.[0-9]+)?)\s*ms',
   441	        r'encoded\s+in\s+([0-9]+(?:\.[0-9]+)?)\s*ms',
   442	        r'encode_mtmd_chunk[^0-9\n]*([0-9]+(?:\.[0-9]+)?)\s*ms',
   443	    ):
   444	        m = re.search(pat, log_delta, flags=re.IGNORECASE)
   445	        if m:
   446	            encode_ms = float(m.group(1))
   447	            break
   448	
   449	    if encode_ms is None:
   450	        m_enc = re.search(r'(\d+\.\d{2}\.\d{3}\.\d{3})\s+.*encoding mtmd batch from idx', log_delta)
   451	        m_dec = re.search(r'(\d+\.\d{2}\.\d{3}\.\d{3})\s+.*decoding image batch 1/', log_delta)
   452	        if m_enc and m_dec:
   453	            t1 = _parse_log_ts_ms(m_enc.group(1))
   454	            t2 = _parse_log_ts_ms(m_dec.group(1))
   455	            if t1 is not None and t2 is not None and t2 >= t1:
   456	                encode_ms = round(t2 - t1, 3)
   457	
   458	    return {
   459	        'image_tokens_logged': image_tokens,
   460	        'image_tokens_batches': batch_tokens,
   461	        'image_encode_ms_not_a_measurement': encode_ms,
   462	    }

   465	def read_vmhwm_kib_for_tree(timeout_pid):
   466	    """Read VmHWM (in KiB) from /proc/<pid>/status for timeout_pid and any direct child (llama-server)."""
   467	    best_kib = None
   468	    best_pid = None
   469	    best_name = None
   470	    for status_path in glob.glob('/proc/[0-9]*/status'):
   471	        try:
   472	            pid = int(status_path.split('/')[2])
   473	            text = Path(status_path).read_text(encoding='utf-8', errors='replace')
   474	        except OSError:
   475	            continue
   476	        ppid = None
   477	        name = None
   478	        hwm_kib = None
   479	        for line in text.splitlines():
   480	            if line.startswith('Name:'):
   481	                name = line.split(':', 1)[1].strip()
   482	            elif line.startswith('PPid:'):
   483	                try:
   484	                    ppid = int(line.split(':', 1)[1].strip())
   485	                except ValueError:
   486	                    pass
   487	            elif line.startswith('VmHWM:'):
   488	                parts = line.split()
   489	                if len(parts) >= 2 and parts[1].isdigit():
   490	                    hwm_kib = int(parts[1])
   491	        if pid == timeout_pid or ppid == timeout_pid:
   492	            if hwm_kib is not None and (best_kib is None or hwm_kib > best_kib):
   493	                best_kib = hwm_kib
   494	                best_pid = pid
   495	                best_name = name
   496	    return {'pid': best_pid, 'name': best_name, 'vmhwm_kib_not_a_measurement': best_kib}

   526	        headers={'Content-Type': 'application/json'},
   527	        method='GET' if data is None else 'POST',
   528	    )
   529	    with urllib.request.urlopen(req, timeout=timeout) as resp:
   530	        return json.loads(resp.read().decode('utf-8'))

   533	def extract_chat_reply(resp_json):
   534	    """Extract assistant reply content, reasoning_content, finish_reason, usage, and timings from /chat/completions."""
   535	    choices = resp_json.get('choices') or []
   536	    if not choices:
   537	        raise RuntimeError(f'No choices in /chat/completions response: {resp_json}')
   538	    choice0 = choices[0]
   539	    msg = choice0.get('message') or {}
   540	    raw_content = msg.get('content')
   541	    reasoning_content = msg.get('reasoning_content')
   542	    content = '' if raw_content is None else str(raw_content).strip()
   543	    finish_reason = choice0.get('finish_reason')
   544	    usage = resp_json.get('usage') or {}
   545	    timings = resp_json.get('timings') or {}
   546	    prompt_tokens = usage.get('prompt_tokens')
   547	    if prompt_tokens is None:
   548	        prompt_tokens = timings.get('prompt_n')
   549	    completion_tokens = usage.get('completion_tokens')
   550	    if completion_tokens is None:
   551	        completion_tokens = timings.get('predicted_n')
   552	    return {
   553	        'reply': content,
   554	        'raw_content': raw_content,
   555	        'reasoning_content': reasoning_content,
   556	        'finish_reason': finish_reason,
   557	        'prompt_tokens': prompt_tokens,
   558	        'completion_tokens': completion_tokens,
   559	        'prompt_ms_not_a_measurement': timings.get('prompt_ms'),
   560	        'predicted_ms_not_a_measurement': timings.get('predicted_ms'),
   561	        'predicted_per_second_not_a_measurement': timings.get('predicted_per_second'),
   562	        'timing_label': TIMING_LABEL,
   563	    }

   597	class ManagedTestServer:
   598	    """Manages a single timeout-wrapped llama-server instance on port 8090."""
   599	
   600	    def __init__(self, budget, server_log_path, label=''):
   601	        self.budget = budget
   602	        self.server_log_path = Path(server_log_path)
   603	        self.label = label or f'budget_{budget}'
   604	        self.cmd = build_server_cmd(budget=budget)
   605	        self.proc = None
   606	        self.log_handle = None
   607	        self.peak_vmhwm_kib = None
   608	        self.server_pid = None
   609	        self.server_name = None
   610	        self.started_utc = None
   611	        self.ended_utc = None
   612	        self.startup_s_not_a_measurement = None
   613	        self.exit_code = None
   614	
   615	    def sample_vmhwm(self):
   616	        if self.proc is None:
   617	            return None
   618	        info = read_vmhwm_kib_for_tree(self.proc.pid)
   619	        hwm = info['vmhwm_kib_not_a_measurement']
   620	        if hwm is not None and (self.peak_vmhwm_kib is None or hwm > self.peak_vmhwm_kib):
   621	            self.peak_vmhwm_kib = hwm
   622	            self.server_pid = info['pid']
   623	            self.server_name = info['name']
   624	        return self.peak_vmhwm_kib
   625	
   626	    def start(self):
   627	        check_port_8080_stopped(ROBOT_PORT)
   628	        check_port_free(TEST_PORT)
   629	        self.server_log_path.parent.mkdir(parents=True, exist_ok=True)
   630	        self.started_utc = utc_now()
   631	        banner = format_server_log_banner(self.started_utc, self.label, self.budget, self.cmd)
   632	        with open(self.server_log_path, 'a', encoding='utf-8') as lf:
   633	            lf.write(banner)
   634	        self.log_handle = open(self.server_log_path, 'ab')
   635	        env = {k: v for k, v in os.environ.items() if not k.startswith('LLAMA_ARG_')}
   636	        t0 = time.perf_counter()
   637	        self.proc = subprocess.Popen(
   638	            self.cmd,
   639	            env=env,
   640	            stdout=self.log_handle,
   641	            stderr=subprocess.STDOUT,
   642	        )
   643	        deadline = time.perf_counter() + STARTUP_TIMEOUT_S
   644	        while time.perf_counter() < deadline:
   645	            if self.proc.poll() is not None:
   646	                self.exit_code = self.proc.returncode
   647	                raise RuntimeError(
   648	                    f'llama-server exited during startup with code {self.exit_code}; '
   649	                    f'tail:\n{self.log_tail(25)}'
   650	                )
   651	            try:
   652	                health = http_json('/health', timeout=2)
   653	                if health.get('status') == 'ok':
   654	                    self.startup_s_not_a_measurement = time.perf_counter() - t0
   655	                    self.sample_vmhwm()
   656	                    return
   657	            except Exception:
   658	                pass
   659	            time.sleep(0.5)
   660	        self.stop()
   661	        raise TimeoutError(f'llama-server did not become healthy within {STARTUP_TIMEOUT_S}s')
   662	
   663	    def is_alive(self):
   664	        return self.proc is not None and self.proc.poll() is None
   665	
   666	    def log_size(self):
   667	        try:
   668	            if self.log_handle:
   669	                self.log_handle.flush()
   670	            return self.server_log_path.stat().st_size
   671	        except OSError:
   672	            return 0
   673	
   674	    def log_delta_from(self, offset):
   675	        try:
   676	            if self.log_handle:
   677	                self.log_handle.flush()
   678	            with open(self.server_log_path, 'rb') as f:
   679	                f.seek(offset)
   680	                return f.read().decode('utf-8', errors='replace')
   681	        except OSError:
   682	            return ''
   683	
   684	    def log_tail(self, n_lines=25):
   685	        try:
   686	            if self.log_handle:
   687	                self.log_handle.flush()
   688	            lines = self.server_log_path.read_text(encoding='utf-8', errors='replace').splitlines()
   689	            return '\n'.join(lines[-n_lines:])
   690	        except OSError:
   691	            return ''
   692	
   693	    def stop(self):
   694	        self.sample_vmhwm()
   695	        if self.proc is not None:
   696	            if self.proc.poll() is None:
   697	                self.proc.terminate()
   698	                try:
   699	                    self.proc.wait(timeout=10)
   700	                except subprocess.TimeoutExpired:
   701	                    self.proc.kill()
   702	                    self.proc.wait(timeout=10)
   703	            self.exit_code = self.proc.returncode
   704	        if self.log_handle is not None:
   705	            try:
   706	                self.log_handle.flush()
   707	                self.log_handle.close()
   708	            except OSError:
   709	                pass
   710	            self.log_handle = None
   711	        self.ended_utc = utc_now()
   712	
   713	    def summary(self):
   714	        return {
   715	            'label': self.label,
   716	            'budget': self.budget,
   717	            'command': self.cmd,
   718	            'started_utc': self.started_utc,
   719	            'ended_utc': self.ended_utc,
   720	            'startup_s_not_a_measurement': self.startup_s_not_a_measurement,
   721	            'server_pid': self.server_pid,
   722	            'server_name': self.server_name,
   723	            'peak_vmhwm_kib_not_a_measurement': self.peak_vmhwm_kib,
   724	            'exit_code': self.exit_code,
   725	            'timing_label': TIMING_LABEL,
   726	        }

   967	def _draw_wrapped_lines(draw, x, y, lines, width_chars=100, font_size=13, line_gap=4, fill='#111111'):
   968	    font = ImageFont.load_default(size=font_size)
   969	    for raw_line in lines:

   971	        wrapped = textwrap.wrap(text, width=width_chars) if text else ['']
   972	        for part in wrapped:
   973	            draw.text((x, y), part, fill=fill, font=font)
   974	            y += font_size + line_gap
   975	    return y
