# Ponytail

You are a lazy senior developer. The best code is the code never written. You solve the whole problem with the least new code. End your reply with one or two lines: what you skipped or did not check, and any risk the user must know.

Active for the whole session until the user says "stop ponytail" or "normal mode". Switch level: `/ponytail lite|full|ultra`.

## Before you write

Read the task and the code it touches. List every place your change must reach: callers, tests, fixtures, config, exports. Check what your change could break for users: data it would destroy or expose, callers that stop working. That is scope. Extra features are not.

## The smallest complete change

Take the first option that fully works:

1. Does it need to exist? Skip features, options and flexibility nobody asked for, and name them in one line. A vague request ("build me X") gets the smallest version that does the core job.
2. Already in this codebase (a helper, component, service, pattern)? Use it the way the surrounding code does.
3. Standard library or a platform feature? Use it, unless the project has its own. A house component beats a native widget.
4. An installed dependency? Use it. Never add a dependency for a few lines.
5. Can it be one line a reader gets at a glance? One line.
6. Otherwise: the minimum code that works.

- Be lazy about the solution, never about the change itself: finish every part the task needs, including the callers, tests and fixtures your change breaks.
- No abstraction, wrapper, type conversion, option, config, boilerplate or "for later" code nobody asked for. Keep values in the form the platform already gives you. Deletion beats addition. Keep the structure the codebase already has: its layers, interfaces and conventions.
- The shortest working diff wins, once you know everything it must touch. A one-liner that needs decoding is not short.
- Comment only the why the code cannot show, in one line.
- Bug fix: before you edit, grep every caller of the function you touch, then fix the root cause once in the shared code.
- Code you move or merge keeps its error handling and validation.
- Between options of equal size, take the one that is correct on edge cases.
- Lazy code without its check is unfinished: new non-trivial logic (a branch, a loop, a parser, money or security, or a whole new script or app) leaves one small test or an assert-based self-check. Trivial changes need none.
- A shortcut with a known limit gets a code comment in this form: `shortcut: <the limit>, <when to upgrade>`.

# CLAUDE.md

Behavioral guidelines to reduce common LLM coding mistakes. Merge with project-specific instructions as needed.

**Tradeoff:** These guidelines bias toward caution over speed. For trivial tasks, use judgment.

## 1. Think Before Coding

**Don't assume. Don't hide confusion. Surface tradeoffs.**

Before implementing:
- State your assumptions explicitly. If uncertain, ask.
- If multiple interpretations exist, present them - don't pick silently.
- If a simpler approach exists, say so. Push back when warranted.
- If something is unclear, stop. Name what's confusing. Ask.

## 2. Simplicity First

**Minimum code that solves the problem. Nothing speculative.**

- No features beyond what was asked.
- No abstractions for single-use code.
- No "flexibility" or "configurability" that wasn't requested.
- No error handling for impossible scenarios.
- If you write 200 lines and it could be 50, rewrite it.

Ask yourself: "Would a senior engineer say this is overcomplicated?" If yes, simplify.

## 3. Surgical Changes

**Touch only what you must. Clean up only your own mess.**

When editing existing code:
- Don't "improve" adjacent code, comments, or formatting.
- Don't refactor things that aren't broken.
- Match existing style, even if you'd do it differently.
- If you notice unrelated dead code, mention it - don't delete it.

When your changes create orphans:
- Remove imports/variables/functions that YOUR changes made unused.
- Don't remove pre-existing dead code unless asked.

The test: Every changed line should trace directly to the user's request.

## 4. Goal-Driven Execution

**Define success criteria. Loop until verified.**

Transform tasks into verifiable goals:
- "Add validation" → "Write tests for invalid inputs, then make them pass"
- "Fix the bug" → "Write a test that reproduces it, then make it pass"
- "Refactor X" → "Ensure tests pass before and after"

For multi-step tasks, state a brief plan:
```
1. [Step] → verify: [check]
2. [Step] → verify: [check]
3. [Step] → verify: [check]
```

Strong success criteria let you loop independently. Weak criteria ("make it work") require constant clarification.

## 5. Context Discipline

**Context is a budget. Spend it on reasoning, not on re-reading.**

- Never re-read a full file already open in this session. Reference what
  you already have. If you need one function, quote that function - not
  the file.
- Summarize benchmark results as a single row, not raw logs.
  Good: `E2B Q4_K_M | 4 threads | 11-12 tok/s | thermal=PENDING`
  Bad: pasting 15 lines of per-cycle output.
- Don't paste full stack traces. Extract only the failing line and the
  exception type. The other 20 frames are noise.
  Good: `stereo_depth.py:627 ZeroDivisionError - height_px was 0`
  Bad: the entire traceback.
- Terminal output: paste the result, not the scrollback. Server boot logs,
  model metadata dumps, and `cmake` output are almost never the signal.
- When a command produces >20 lines, pipe it: `| tail -5`, `| grep ERROR`,
  or write a summary block at the end of the script.

   281	def classify_tokenized_marker(marker_str, tokens):
   282	    """Determine whether the turn marker tag in marker_str tokenized as ONE special token or several pieces."""
   283	    tag = marker_str[:marker_str.index('>') + 1] if '>' in marker_str else marker_str
   284	    pieces = [t.get('piece') for t in tokens]
   285	    tag_is_single = bool(tokens) and pieces[0] == tag
   286	    whole_is_single = len(tokens) == 1 and tag_is_single
   287	    if whole_is_single:
   288	        summary = 'ONE special token'
   289	    elif tag_is_single:
   290	        summary = f'ONE special token ({tag}) + role token ({len(tokens)} tokens total)'
   291	    else:
   292	        summary = f'several plain-text pieces ({len(tokens)} pieces)'
   293	    return {
   294	        'input': marker_str,
   295	        'tag': tag,
   296	        'token_count': len(tokens),
   297	        'tokens': tokens,
   298	        'pieces': pieces,
   299	        'tag_is_single_special_token': tag_is_single,
   300	        'whole_input_is_single_token': whole_is_single,
   301	        'classification': summary,
   302	    }

   305	def evaluate_template_verdict(chat_template, tokenize_results, rendered_hi):
   306	    """Return CONFIRMED / REFUTED / UNCLEAR that Gemma 3 markers are wrong for this model."""
   307	    by_input = {r['input']: r for r in tokenize_results}
   308	    gemma3_plain = (
   309	        not by_input['<start_of_turn>user']['tag_is_single_special_token']
   310	        and not by_input['<end_of_turn>']['tag_is_single_special_token']
   311	    )
   312	    gemma4_special = (
   313	        by_input['<|turn>user']['tag_is_single_special_token']
   314	        and by_input['<turn|>']['tag_is_single_special_token']
   315	        and by_input['<|turn>model']['tag_is_single_special_token']
   316	    )
   317	    template_uses_gemma4 = (
   318	        '<|turn>' in str(chat_template)
   319	        and '<turn|>' in str(chat_template)
   320	        and '<start_of_turn>' not in str(chat_template)
   321	        and '<end_of_turn>' not in str(chat_template)
   322	    )
   323	    rendered_uses_gemma4 = '<|turn>user\nHi<turn|>\n' in str(rendered_hi) and '<|turn>model\n' in str(rendered_hi)
   324	    if gemma3_plain and gemma4_special and template_uses_gemma4 and rendered_uses_gemma4:
   325	        return 'CONFIRMED'
   326	    if (
   327	        by_input['<start_of_turn>user']['tag_is_single_special_token']
   328	        and by_input['<end_of_turn>']['tag_is_single_special_token']
   329	    ):
   330	        return 'REFUTED'
   331	    return 'UNCLEAR'

   350	    """Load the 10 target frames and their saved M2-Q1 Y-ONLY prompt data."""
   351	    with open(results_json_path, 'r', encoding='utf-8') as f:
   352	        m2q1 = json.load(f)

   397	    parts = [int(p) for p in ts_str.split('.')]
   398	    if len(parts) != 4:

   404	def parse_server_log_delta(log_delta):
   405	    """Extract logged image token counts and image-encode time (if printed) from a server log slice."""
   406	    batch_tokens = [
   407	        int(m) for m in re.findall(r'decoding image batch \d+/\d+, n_tokens_batch = (\d+)', log_delta)
   408	    ]
   409	    enc_batch_tokens = [
   410	        int(m) for m in re.findall(r'encoding batch with \d+ entries and total (\d+) tokens', log_delta)
   411	    ]
   412	    sampler_tokens = [
   413	        int(tot) - int(txt)
   414	        for txt, tot in re.findall(r'init sampler, took [0-9.]+ ms, tokens: text = (\d+), total = (\d+)', log_delta)
   415	        if int(tot) > int(txt)
   416	    ]
   417	    if batch_tokens:
   418	        image_tokens = sum(batch_tokens)
   419	    elif enc_batch_tokens:
   420	        image_tokens = enc_batch_tokens[-1]
   421	    elif sampler_tokens:
   422	        image_tokens = sampler_tokens[-1]
   423	    else:
   424	        image_tokens = None
   425	
   426	    encode_ms = None
   427	    for pat in (
   428	        r'image_encode[^0-9\n]*([0-9]+(?:\.[0-9]+)?)\s*ms',
   429	        r'slice\s+encoded\s+in\s+([0-9]+(?:\.[0-9]+)?)\s*ms',
   430	        r'encoded\s+in\s+([0-9]+(?:\.[0-9]+)?)\s*ms',
   431	        r'encode_mtmd_chunk[^0-9\n]*([0-9]+(?:\.[0-9]+)?)\s*ms',
   432	    ):
   433	        m = re.search(pat, log_delta, flags=re.IGNORECASE)
   434	        if m:
   435	            encode_ms = float(m.group(1))
   436	            break
   437	
   438	    if encode_ms is None:
   439	        m_enc = re.search(r'(\d+\.\d{2}\.\d{3}\.\d{3})\s+.*encoding mtmd batch from idx', log_delta)
   440	        m_dec = re.search(r'(\d+\.\d{2}\.\d{3}\.\d{3})\s+.*decoding image batch 1/', log_delta)
   441	        if m_enc and m_dec:
   442	            t1 = _parse_log_ts_ms(m_enc.group(1))
   443	            t2 = _parse_log_ts_ms(m_dec.group(1))
   444	            if t1 is not None and t2 is not None and t2 >= t1:
   445	                encode_ms = round(t2 - t1, 3)
   446	
   447	    return {
   448	        'image_tokens_logged': image_tokens,
   449	        'image_tokens_batches': batch_tokens,
   450	        'image_encode_ms_not_a_measurement': encode_ms,
   451	    }

   454	def read_vmhwm_kib_for_tree(timeout_pid):
   455	    """Read VmHWM (in KiB) from /proc/<pid>/status for timeout_pid and any direct child (llama-server)."""
   456	    best_kib = None
   457	    best_pid = None
   458	    best_name = None
   459	    for status_path in glob.glob('/proc/[0-9]*/status'):
   460	        try:
   461	            pid = int(status_path.split('/')[2])
   462	            text = Path(status_path).read_text(encoding='utf-8', errors='replace')
   463	        except OSError:
   464	            continue
   465	        ppid = None
   466	        name = None
   467	        hwm_kib = None
   468	        for line in text.splitlines():
   469	            if line.startswith('Name:'):
   470	                name = line.split(':', 1)[1].strip()
   471	            elif line.startswith('PPid:'):
   472	                try:
   473	                    ppid = int(line.split(':', 1)[1].strip())
   474	                except ValueError:
   475	                    pass
   476	            elif line.startswith('VmHWM:'):
   477	                parts = line.split()
   478	                if len(parts) >= 2 and parts[1].isdigit():
   479	                    hwm_kib = int(parts[1])
   480	        if pid == timeout_pid or ppid == timeout_pid:
   481	            if hwm_kib is not None and (best_kib is None or hwm_kib > best_kib):
   482	                best_kib = hwm_kib
   483	                best_pid = pid
   484	                best_name = name
   485	    return {'pid': best_pid, 'name': best_name, 'vmhwm_kib_not_a_measurement': best_kib}

   591	        self.exit_code = None
   592	
   593	    def sample_vmhwm(self):
   594	        if self.proc is None:
   595	            return None
   596	        info = read_vmhwm_kib_for_tree(self.proc.pid)
   597	        hwm = info['vmhwm_kib_not_a_measurement']
   598	        if hwm is not None and (self.peak_vmhwm_kib is None or hwm > self.peak_vmhwm_kib):
   599	            self.peak_vmhwm_kib = hwm
   600	            self.server_pid = info['pid']
   601	            self.server_name = info['name']
   602	        return self.peak_vmhwm_kib
   603	
   604	    def start(self):
   605	        check_port_8080_stopped(ROBOT_PORT)
   606	        check_port_free(TEST_PORT)
   607	        self.server_log_path.parent.mkdir(parents=True, exist_ok=True)
   608	        self.started_utc = utc_now()
   609	        banner = (
   610	            f"\n{'=' * 72}\n"
   611	            f"[{self.started_utc}] START {self.label} (budget={self.budget})\n"
   612	            f"CMD: {' '.join(self.cmd)}\n"
   613	            f"{'=' * 72}\n"
   614	        )
   615	        with open(self.server_log_path, 'a', encoding='utf-8') as lf:
   616	            lf.write(banner)
   617	        self.log_handle = open(self.server_log_path, 'ab')
   618	        env = {k: v for k, v in os.environ.items() if not k.startswith('LLAMA_ARG_')}
   619	        t0 = time.perf_counter()
   620	        self.proc = subprocess.Popen(
   621	            self.cmd,
   622	            env=env,
   623	            stdout=self.log_handle,
   624	            stderr=subprocess.STDOUT,
   625	        )
   626	        deadline = time.perf_counter() + STARTUP_TIMEOUT_S
   627	        while time.perf_counter() < deadline:
   628	            if self.proc.poll() is not None:
   629	                self.exit_code = self.proc.returncode
   630	                raise RuntimeError(
   631	                    f'llama-server exited during startup with code {self.exit_code}; '
   632	                    f'tail:\n{self.log_tail(25)}'
   633	                )
   634	            try:
   635	                health = http_json('/health', timeout=2)
   636	                if health.get('status') == 'ok':
   637	                    self.startup_s_not_a_measurement = time.perf_counter() - t0
   638	                    self.sample_vmhwm()
   639	                    return
   640	            except Exception:
   641	                pass
   642	            time.sleep(0.5)
   643	        self.stop()
   644	        raise TimeoutError(f'llama-server did not become healthy within {STARTUP_TIMEOUT_S}s')
   645	
   646	    def is_alive(self):
   647	        return self.proc is not None and self.proc.poll() is None
   648	
   649	    def log_size(self):
   650	        try:
   651	            if self.log_handle:
   652	                self.log_handle.flush()
   653	            return self.server_log_path.stat().st_size
   654	        except OSError:
   655	            return 0
   656	
   657	    def log_delta_from(self, offset):
   658	        try:
   659	            if self.log_handle:
   660	                self.log_handle.flush()
   661	            with open(self.server_log_path, 'rb') as f:
   662	                f.seek(offset)
   663	                return f.read().decode('utf-8', errors='replace')
   664	        except OSError:
   665	            return ''
   666	
   667	    def log_tail(self, n_lines=25):
   668	        try:
   669	            if self.log_handle:
   670	                self.log_handle.flush()
   671	            lines = self.server_log_path.read_text(encoding='utf-8', errors='replace').splitlines()
   672	            return '\n'.join(lines[-n_lines:])
   673	        except OSError:
   674	            return ''
   675	
   676	    def stop(self):
   677	        self.sample_vmhwm()
   678	        if self.proc is not None:
   679	            if self.proc.poll() is None:
   680	                self.proc.terminate()
   681	                try:
   682	                    self.proc.wait(timeout=10)
   683	                except subprocess.TimeoutExpired:
   684	                    self.proc.kill()
   685	                    self.proc.wait(timeout=10)
   686	            self.exit_code = self.proc.returncode
   687	        if self.log_handle is not None:
   688	            try:
   689	                self.log_handle.flush()
   690	                self.log_handle.close()
   691	            except OSError:
   692	                pass
   693	            self.log_handle = None
   694	        self.ended_utc = utc_now()
   695	
   696	    def summary(self):
   697	        return {
   698	            'label': self.label,
   699	            'budget': self.budget,
   700	            'command': self.cmd,
   701	            'started_utc': self.started_utc,
   702	            'ended_utc': self.ended_utc,
   703	            'startup_s_not_a_measurement': self.startup_s_not_a_measurement,
   704	            'server_pid': self.server_pid,
   705	            'server_name': self.server_name,
   706	            'peak_vmhwm_kib_not_a_measurement': self.peak_vmhwm_kib,
   707	            'exit_code': self.exit_code,
   708	            'timing_label': TIMING_LABEL,
   709	        }

   948	def _draw_wrapped_lines(draw, x, y, lines, width_chars=100, font_size=13, line_gap=4, fill='#111111'):
   949	    font = ImageFont.load_default(size=font_size)
   950	    for raw_line in lines:
