1. **P1 — A successful restart crossing the deadline overcounts pause time in a potentially VALID arm.**

   `benchmark/mind_picker/b5_mission/b5.py:717` — **1,000 lines**:
   > `out.append((began, r['t']))`

   `benchmark/mind_picker/b5_mission/b5.py:641` — **1,000 lines**:
   > `rec['mission_end_s'] = min(m.rel(clock()), ctx['dur'])`

   `benchmark/mind_picker/b5_mission/b5.py:751` — **1,000 lines**:
   > `'active_share': round(1 - total / end_t, 3) if end_t else None,`

   The owner explicitly allows an underway transition to finish after the deadline. Its successful ACTIVE `done` row can therefore be later than `mission_end_s`. Closed pause intervals use that uncapped completion time, while the denominator is capped to mission duration.

   For example, a pause beginning at 100 seconds and a restart completing at 1,802 seconds yields 1,702 seconds of pause against an 1,800-second mission, although only 1,700 seconds occurred inside mission time. This can pass the 15-second overrun rule. More extreme boundary cases can produce negative ACTIVE share.

   **Concrete fix:** Intersect every pause interval with the mission interval `[0, end_t]` before summing. Preserve the actual transition completion timestamp and successful-resume record separately. Extend the fake-clock deadline-crossing test to assert pause duration and ACTIVE share when camera start itself completes after the deadline.

2. **P2 — Concurrent re-pin recording can attach another operation’s record to a watcher scan.**

   `benchmark/mind_picker/b5_mission/b5.py:439` — **1,000 lines**:
   > `self.events.append({'mono': round(time.monotonic(), 3), **ev})`

   `benchmark/mind_picker/b5_mission/b5.py:440` — **1,000 lines**:
   > `return self.events[-1]`

   `benchmark/mind_picker/b5_mission/b5.py:502` — **1,000 lines**:
   > `x['repins'] = [rp.server('watch') if p == 'llama_server' else rp.detector('watch') for p in sorted(drift)]`

   The append is locked, but selecting the returned event happens after releasing the lock. A camera-start operation on the mission thread can append between a watcher append and its return. The watcher then stores the camera-start event in its scan’s `repins`, potentially with the wrong trigger or process.

   The global event list retains both entries, so this does not itself demonstrate an incorrect final validity label. It does break the requested association between a drift scan and its corrective operation. Existing re-pin tests run these operations sequentially.

   **Concrete fix:** Construct a local event object, append that object under the lock, and return that same object. Add a deterministic concurrency test verifying that each caller receives its own event and that watcher samples retain the matching watch-triggered correction.

 196              if row.get('cancelled'):
 197                  if self.pending is None and now < self.deadline:
 198                      ev['fate'], self.pending = 'pending', ev  # back in the queue; latency still from its offer
 199                  else:
 200                      ev['fate'] = 'cancelled'
 201              elif 'error' in row:
 202                  ev['fate'] = 'error'
 203              else:
 204                  ev.update(fate='served', top=row['top'], latency_s=round(ev['ended'] - ev['offered'], 3),
 205                            wait_s=round(ev['started'] - ev['offered'], 3))
 206  
 207      def close(self):
 208          with self.lock:
 209              if self.pending:
 210                  self.pending['fate'] = 'unserved'
 211              self.pending = None

 216  def picker_setup(test):
 217      """(prompts of all 40 TEST items, V3 FWD; their common prefix ids); any problem raises."""
 218      info = {'problems': []}
 219      prompts = b2.preflight(b4.post, test, [('V3', 'FWD')], info, 'TEST')

 221          raise RuntimeError(f'picker preflight: {info["problems"]}')

 226  class Checked(b4.Recorder):
 227      """b4.Recorder that checks the picker (its generation and permission) before every request and again after
 228      every response (picker.Picker's check()): a forbid at any time, even one followed by an allow, cancels."""
 229  
 230      def __init__(self, ok):
 231          super().__init__()
 232          self.ok = ok
 233  
 234      def __call__(self, path, body):
 235          if not self.ok():
 236              raise Cancelled('picker forbidden (left ACTIVE, SEVERE or stop)')
 237          res = super().__call__(path, body)
 238          if not self.ok():
 239              raise Cancelled(f'picker forbidden while {path} was in flight')
 240          return res

 243  def real_item(n, text):
 244      return {'id': f'R{n}', 'mission': REAL_MISSION, 'current': REAL_CURRENT, 'event': text, 'memory': None,
 245              'allowed': list(b2.NAMES)}

 248  def decide(ev, ok, prompts, test):
 249      """One decision row: restore before every RESTORE_EVERY-th, a real event's prompt rendered, then b2.score V3 FWD."""
 250      rec = Checked(ok)
 251      row = {'kind': 'decision', 'source': ev['source'], 'id': ev['item']['id'], 'n': ev['n']}
 252      t0 = time.perf_counter()
 253      try:
 254          if ev['n'] % RESTORE_EVERY == 0:
 255              if not ok():
 256                  raise Cancelled('picker forbidden before the restore')
 257              row['restore'] = b4.slot('restore')
 258              if not ok():
 259                  raise Cancelled('picker forbidden while the restore was in flight')
 260          it = ev['item']
 261          prompt = prompts.get(('V3', 'FWD', it['id']))
 262          if prompt is None:
 263              r0, info = time.perf_counter(), {'problems': []}
 264              prompt = b2.preflight(rec, {**test, 'items': [it]}, [('V3', 'FWD')], info, 'REAL')['V3', 'FWD', it['id']]
 265              row['render_s'] = round(time.perf_counter() - r0, 3)
 266              if info['problems']:
 267                  raise RuntimeError(f'real event prompt: {info["problems"]}')
 268          n0 = len(rec.completions)
 269          r = b2.score(rec, it, 'V3', 'FWD', prompt)
 270          if not ok():
 271              raise Cancelled('picker forbidden before the result was accepted')
 272          t1, t2 = (x.get('timings', {}) for x in rec.completions[n0:])
 273          row.update(top=r['top'], reason=r['reason'], reason_tokens=r['reason_tokens'],
 274                     gen_tok_s=t1.get('predicted_per_second'), step1_prompt_n=t1.get('prompt_n'),
 275                     step1_cache_n=t1.get('cache_n'), step2_prompt_n=t2.get('prompt_n'), step2_cache_n=t2.get('cache_n'))
 276      except Cancelled as e:
 277          row.update(cancelled=True, reason=str(e))
 278      except Exception as e:
 279          row['error'] = f'{type(e).__name__}: {e}'
 280      row.update(wall_s=round(time.perf_counter() - t0, 3), endpoint_s=rec.seconds, cores_ok=b4.cores_ok())
 281      return row

 284  def scheduler(m, skin, halt, run, out):
 285      """Offers the scripted items and starts decisions until the deadline has passed with none in flight, or halt."""
 286      th = None
 287      try:
 288          while not halt.is_set():
 289              now = clock()
 290              m.offer_due(now)
 291              if go := m.start(now, skin()):
 292                  th = threading.Thread(target=run, args=go, daemon=True)
 293                  th.start()
 294              if now >= m.deadline and m.busy is None:
 295                  break
 296              halt.wait(POLL_S)
 297      except Exception as e:
 298          out['error'] = f'scheduler: {type(e).__name__}: {e}'
 299      finally:
 300          if th:
 301              th.join(JOIN_S)
 302              out['alive'] = th.is_alive()

 312  def mission_loop(robot, heat, m, rec, add, read, cam, ready=lambda: None, repin=lambda: None):
 313      """Robot.run_mission motors-off (see the module docstring) until the deadline. Returns at heat END, a camera
 314      failure or a battery stop, with the reason in rec['errors']. ready() is called once, right after the first heat /
 315      SEVERE assessment has set the picker's permission (the start barrier: the scheduler starts there). Heat rows:
 316      stage 'intent' when a transition begins, stage 'done' when it completed (into ACTIVE: camera started and ACTIVE
 317      entered). Detections of a cycle admitted before the deadline that end after it offer no real event (counted in
 318      rec['late_not_offered'])."""
 319      last = prev = None
 320      no_new = n_real = 0
 321      rec.setdefault('late_not_offered', 0)
 322      first = True
 323      while clock() < m.deadline:
 324          target, reason = heat.decide(999)  # dry run: get_distance() is 999
 325          sev = severe(heat)
 326          if sev:
 327              m.set_ok(False)
 328          if target == 'END':
 329              rec['errors'].append(f'heat END: {reason}')
 330              return
 331          if target != heat.phase:
 332              frm = heat.phase
 333              add({'kind': 'heat', 'stage': 'intent', 'from': frm, 'to': target, 'reason': reason, 't': m.rel(clock())})
 334              if heat.phase == 'ACTIVE':
 335                  m.set_ok(False)
 336                  st = b4.stop_camera(robot)
 337                  rec['camera_stops'].append(st)
 338                  if st.get('error') or st.get('affinity_error'):
 339                      heat.event('camera_stop_fail', st.get('error') or st.get('affinity_error'))
 340                      rec['errors'].append(f'camera stop at pause: {st}')
 341                      return
 342                  cam['on'] = False
 343                  heat.event('camera_stop_ok')
 344                  heat.enter(target, since=heat.now())
 345                  add({'kind': 'heat', 'stage': 'done', 'from': frm, 'to': target, 't': m.rel(clock())})
 346                  if not read('pause_start'):
 347                      return
 348              elif target == 'ACTIVE':
 349                  started = heat.now()
 350                  cam['on'] = True  # a start attempted: cleanup stops it
 351                  try:
 352                      robot.start_camera(heat)
 353                  except Exception as e:
 354                      heat.event('camera_start_fail', str(e))
 355                      rec['errors'].append(f'camera start after pause: {type(e).__name__}: {e}')
 356                      return
 357                  heat.event('camera_start_ok')
 358                  repin()  # llama-server threads to 4-7 at every camera start (the detector: main.py's start_camera)
 359                  heat.enter('ACTIVE', since=started)
 360                  add({'kind': 'heat', 'stage': 'done', 'from': frm, 'to': 'ACTIVE', 't': m.rel(clock())})
 361                  last, cam['slot'] = None, cam['slot'] + 1
 362                  sev = severe(heat)
 363                  m.set_ok(not sev)  # main.py: picker.allow() right after ACTIVE entry, before our reading
 364                  try:
 365                      if not read('pause_end'):
 366                          m.set_ok(False)
 367                          return
 368                  except BaseException:
 369                      m.set_ok(False)
 370                      raise
 371              else:
 372                  heat.enter(target)
 373                  add({'kind': 'heat', 'stage': 'done', 'from': frm, 'to': target, 't': m.rel(clock())})
 374          m.set_ok(heat.phase == 'ACTIVE' and not sev)
 375          if first:
 376              first = False
 377              ready()
 378          if heat.phase == 'HOLD':
 379              pause(1)
 380              continue
 381          if heat.phase == 'PAUSE':
 382              pause(min(main.CYCLE_MOVE_TIME, max(0.0, m.deadline - clock())))
 383              continue
 384          c0 = clock()
 385          if c0 >= m.deadline:  # a transition or reading crossed it: no new cycle
 386              break
 387          r = main.read_frame(session=robot.camera_session)
 388          if r['status'] != 'ok' or (last is not None and r['frame'] <= last):
 389              why = r['status'] if r['status'] != 'ok' else 'no new'
 390              add({'kind': 'camera_stop', 'reason': why, 't': m.rel(c0)})
 391              no_new += why == 'no new'
 392              if why != 'no new' or no_new > b4.NO_NEW_MAX:
 393                  rec['errors'].append(f'camera stop: {why} ({no_new} no new)')
 394                  return
 395              pause(0.1)
 396              continue
 397          last, robot.camera_session = r['frame'], r['session']
 398          size = robot.size_policy.next_size()
 399          row = {'kind': 'cycle', 't': m.rel(c0), 'slot': cam['slot'], 'frame': r['frame'], 'age_s': r['age_s'],
 400                 'size': size}
 401          try:
 402              d0 = time.perf_counter()
 403              dets = robot.detector.detect(r['image'], size)
 404              row.update(detect_ms=round((time.perf_counter() - d0) * 1000, 1), n_det=len(dets))
 405              robot.size_policy.observe(dets, r['image'].height)
 406              person = next((x for x in scene_from_detections(dets, *r['image'].size) if x[0] == 'person'), None)
 407          except Exception as e:
 408              row['error'] = f'{type(e).__name__}: {e}'
 409          row['cores_ok'] = b4.cores_ok()
 410          add(row)
 411          if 'error' in row:
 412              rec['errors'].append(f'camera cycle: {row["error"]}')
 413              return
 414          cur = person[3] if person else None
 415          text = person_event(prev, cur)
 416          if text and clock() >= m.deadline:
 417              rec['late_not_offered'] += 1  # admitted before the deadline, ended after it
 418          elif text:
 419              n_real += 1
 420              m.offer({'source': 'real', 'id': f'R{n_real}', 'item': real_item(n_real, text), 'text': text}, clock())
 421          prev = cur
 422          pause(min(main.CYCLE_MOVE_TIME, max(0.0, m.deadline - clock())))

 429  class Repinner:
 430      """Re-pins like a robot would: every llama-server thread to SERVER_CPUS (os.sched_setaffinity per thread) and the
 431      detector to 4-5 (its own check_affinity, as main.py). Every re-pin is recorded in events (mono, trigger, process,
 432      threads, before/after, ok). Called from the mission thread and the watcher thread (lock)."""
 433  
 434      def __init__(self, targets):
 435          self.targets, self.events, self.lock = targets, [], threading.Lock()
 436  
 437      def add(self, ev):
 438          ev = {'mono': round(time.monotonic(), 3), **ev}  # this caller's own event object
 439          with self.lock:
 440              self.events.append(ev)
 441          return ev
 442  
 443      def server(self, trigger):
 444          pid = self.targets.get('server_pid')
 445          before, after, errors = {}, {}, {}
 446          try:
 447              tids = sorted(int(t.name) for t in (b4.PROC / str(pid) / 'task').iterdir())
 448          except OSError as e:
 449              return self.add({'trigger': trigger, 'process': 'llama_server', 'ok': False, 'errors': {'task': str(e)}})
 450          for tid in tids:
 451              try:
 452                  before[tid] = sorted(os.sched_getaffinity(tid))
 453                  if set(before[tid]) != b4.SERVER_CPUS:
 454                      os.sched_setaffinity(tid, b4.SERVER_CPUS)
 455                      after[tid] = sorted(os.sched_getaffinity(tid))
 456                      if set(after[tid]) != b4.SERVER_CPUS:
 457                          errors[tid] = f'after {after[tid]}'
 458              except ProcessLookupError:
 459                  before.pop(tid, None)  # the thread ended: nothing to pin
 460              except OSError as e:
 461                  errors[tid] = f'{type(e).__name__}: {e}'
 462          return self.add({'trigger': trigger, 'process': 'llama_server', 'threads': sorted(after),
 463                           'before': before, 'after': after, 'ok': not errors, 'errors': errors})
 464  
 465      def detector(self, trigger, result=None):
 466          """result: a check_affinity() result already obtained (main.py's at camera start); else one is run now."""
 467          r = result if result is not None else self.targets['detector'].check_affinity()
 468          return self.add({'trigger': trigger, 'process': 'detector', 'threads': r['repinned'], 'before': r['before'],
 469                           'after': r['after'], 'ok': r['ok'], 'errors': r['errors']})

 472  DRIFT = {'llama_server': re.compile(r'llama-server thread \d+ Cpus_allowed_list'),
 473           'detector': re.compile(r'detector threads \{')}

 476  def groups(targets):
 477      """/proc/<pid>/cpuset and cgroup of llama-server, the runner and the detector caller thread (error text when
 478      unreadable): shows whether Android moved Termux between CPU groups."""
 479      paths = {'runner': b4.PROC / str(os.getpid())}
 480      if targets.get('server_pid') is not None:
 481          paths['llama_server'] = b4.PROC / str(targets['server_pid'])
 482      if targets.get('detector') is not None:
 483          paths['detector'] = b4.PROC / str(os.getpid()) / 'task' / str(targets['detector'].caller_tid)
 484      out = {}
 485      for name, p in paths.items():
 486          for f in ('cpuset', 'cgroup'):
 487              try:
 488                  out[f'{name}_{f}'] = (p / f).read_text().strip()
 489              except OSError as e:
 490                  out[f'{name}_{f}'] = f'{type(e).__name__}: {e}'
 491      return out

 494  def scan(targets, rp):
 495      """b4.watch_check, then drift (a llama-server thread off 4-7, a detector thread off 4-5) is split from the other
 496      hits and re-pinned at once; the CPU groups are recorded."""
 497      x = b4.watch_check(targets)
 498      hits, drift = [], {}
 499      for h in x['hits']:
 500          p = next((k for k, rx in DRIFT.items() if rx.match(h)), None)
 501          (drift.setdefault(p, []) if p else hits).append(h)
 502      x.update(hits=hits, drift=drift, groups=groups(targets))
 503      x['repins'] = [rp.server('watch') if p == 'llama_server' else rp.detector('watch') for p in sorted(drift)]
 504      return x

 507  def watch_problems(w, repins):
 508      """b4's watcher rules, except that drift corrected by one re-pin is recorded, not a problem; INVALID when any
 509      re-pin fails or the same process is drifted in two consecutive scans."""
 510      why = b4.thread_problems(w, 'watch')
 511      why += [f'watch: {h}' for x in w['samples'] for h in x['hits']]
 512      why += [f're-pin failed ({e["trigger"]}, {e["process"]}): {e.get("errors")}' for e in repins if not e['ok']]
 513      for a, b in zip(w['samples'], w['samples'][1:]):
 514          why += [f'watch: {p} drifted in two consecutive scans ({a["mono"]}, {b["mono"]})'
 515                  for p in sorted(set(a.get('drift', {})) & set(b.get('drift', {})))]
 516      return why if w['samples'] else why + ['watch: no scan']

 535  def arm_problems(rec, rows):
 536      """Why an arm is INVALID (empty: VALID)."""
 537      why = list(rec['errors'])
 538      for k in ('start', 'end'):
 539          if not any(c['tag'] == k for c in rec['readings']):
 540              why.append(f'{k} reading missing')
 541      for c in rec['readings']:
 542          why += b4.reading_problems(c, c['tag'], need(c))
 543      if rec.get('agents_before') or rec.get('agents_after'):
 544          why.append(f'agent process running: {(rec.get("agents_before") or rec.get("agents_after"))[:120]!r}')
 545      if not rec.get('cores_before') or not rec.get('cores_after') or any(r.get('cores_ok') is False for r in rows):
 546          why.append('cores 4-7 not all allowed during the arm')
 547      if n := sum('error' in r for r in rows):
 548          why.append(f'{n} request/cycle errors')
 549      if not any(r['kind'] == 'cycle' for r in rows):
 550          why.append('no camera cycles')
 551      stops = [r['reason'] for r in rows if r['kind'] == 'camera_stop']
 552      why += [f'camera stop: {s}' for s in stops if s != 'no new']
 553      if stops.count('no new') > b4.NO_NEW_MAX:
 554          why.append(f'{stops.count("no new")} "no new" frames > {b4.NO_NEW_MAX}')
 555      if rec.get('overrun_s', 0) > OVERRUN_MAX_S:
 556          why.append(f'overrun {rec["overrun_s"]} s > {OVERRUN_MAX_S} s')
 557      why += [f'cleanup camera stop: {rec["camera_end"][k]}' for k in ('affinity_error', 'error')
 558              if rec.get('camera_end', {}).get(k)]
 559      if 'watch' in rec:
 560          why += watch_problems(rec['watch'], rec.get('repins', []))
 561      else:
 562          why += [f're-pin failed ({e["trigger"]}, {e["process"]}): {e.get("errors")}'
 563                  for e in rec.get('repins', []) if not e['ok']]
 564      return why

 567  def run_arm(name, out, ctx, emit):
 568      """One arm; its rows go to requests.jsonl through emit; returns (record, rows)."""
 569      rec = {'arm': name, 'session': ctx['session'], 'utc_start': cr.utc(), 'work_s': ctx['dur'], 'errors': [],
 570             'readings': [], 'camera_stops': [], 'cores_before': b4.cores_ok(), 'agents_before': repro.agents()}
 571      rows, lock = [], threading.Lock()
 572  
 573      def add(row):
 574          row = {'arm': name, 'session': ctx['session'], **row}
 575          with lock:
 576              rows.append(row)
 577              emit(row)
 578      if not ctx['smoke'] and (rec['agents_before'] or not rec['cores_before']):
 579          rec['errors'].append('initial agent/cores check failed: no workload started')
 580          rec.update(utc_end=cr.utc(), cores_after=b4.cores_ok(), agents_after=repro.agents())
 581          rec['problems'], rec['label'] = arm_problems(rec, rows), 'INVALID'
 582          rec['metrics'] = metrics(rec, rows, ctx['record'], out)  # the same schema as every other arm record
 583          return rec, rows
 584      proc = log = robot = heat = watch = th = m = None
 585      rp = None
 586      cam = {'on': False, 'slot': 1}
 587      halt, sched = threading.Event(), {}
 588      pids, targets = {'runner': os.getpid()}, {}
 589  
 590      def read(tag):
 591          c = {'tag': tag, 'camera': cam['on'], **b4.reading(pids)}
 592          c['t'] = m.rel(c['mono']) if m else None
 593          rec['readings'].append(c)
 594          if isinstance(c.get('battery_pct'), int) and c['battery_pct'] < BATTERY_STOP_PCT:
 595              rec['errors'].append(f'battery {c["battery_pct"]} % < {BATTERY_STOP_PCT} %: session stopped')
 596              rec['battery_stop'] = True
 597              return False
 598          return True
 599      try:
 600          if bad := [x for x in ('motors', 'serial') if x in sys.modules]:
 601              raise RuntimeError(f'refused: {bad} imported')
 602          main.get_detector(pinned=True)  # before any thread of this process (run_mission's order)
 603          proc, log, rec['load_s'] = b4.start_server(out, f'{ctx["session"]:02d}_{name}', b4.server_command(out, 'P'))
 604          pids['llama_server'] = targets['server_pid'] = proc.pid
 605          prompts, prefix = picker_setup(ctx['test'])
 606          rec['warm'] = b4.warm(prefix)
 607          robot = main.Robot(None)
 608          heat = heat_control.HeatControl(heat_control.HeatMonitor(), trace_dir=str(out))
 609          rp = Repinner(targets)
 610          record_camera_repins(heat, rp)
 611          heat.start()
 612          rec['heat_trace'] = Path(heat.trace_path).name
 613          cam['on'] = True
 614          robot.start_camera(heat)  # main.py re-pins the detector (recorded through record_camera_repins)
 615          targets['detector'] = robot.detector
 616          rp.server('arm_start')
 617          rec['camera'] = {'detector': robot.detector.config(), 'affinity_start': robot.detector.affinity()}
 618          if read('start'):
 619              if ctx['smoke']:  # smoke only: thresholds from this arm's start skin (timed runs: 37/35 degC)
 620                  if (skin := rec['readings'][-1].get('skin')) is None:
 621                      raise RuntimeError('smoke: no arm-start skin for the smoke heat thresholds')
 622                  rec['heat_thresholds'] = smoke_thresholds(skin)
 623              watch = b4.Periodic(lambda: scan(targets, rp), b4.WATCH_S).start()
 624              m = Mission(name, clock(), ctx['dur'], ctx['test']['items'])
 625              start = next(c for c in rec['readings'] if c['tag'] == 'start')
 626              start['t'] = m.rel(start['mono'])  # taken before t0: its real relative time, usually negative
 627  
 628              def run(ev, gen):
 629                  row = {'kind': 'decision', 'error': 'not run'}
 630                  try:
 631                      row = decide(ev, lambda: m.allowed(gen) and not halt.is_set(), prompts, ctx['test'])
 632                  finally:
 633                      m.done(ev, row, clock())
 634                      add({**row, 'offered': ev['offered'], 'started': ev['started'], 'ended': ev['ended'],
 635                           'fate': ev['fate']})
 636              skin = lambda: (heat.monitor.readings()['dump'] or {}).get('skin')  # noqa: E731
 637              def ready():  # start barrier: after the first heat / SEVERE assessment set the permission
 638                  nonlocal th
 639                  th = threading.Thread(target=scheduler, args=(m, skin, halt, run, sched), daemon=True)
 640                  th.start()
 641              mission_loop(robot, heat, m, rec, add, read, cam, ready, lambda: rp.server('camera_start'))
 642              rec['mission_end_s'] = min(m.rel(clock()), ctx['dur'])
 643              if rec['errors']:
 644                  halt.set()  # the arm failed: cancel the decision in flight
 645              if th:
 646                  th.join(JOIN_S + 5)
 647              rec['overrun_s'] = round(max(0.0, clock() - m.deadline), 3)
 648              read('end')
 649      except BaseException as e:  # recorded; cleanup below; a stop (signal) re-raises after the record is kept
 650          rec['errors'].append(f'{type(e).__name__}: {e}')
 651          if not isinstance(e, Exception):
 652              rec['interrupted'] = True
 653      finally:
 654          halt.set()
 655          if th:
 656              b4.cleanup(rec, 'scheduler', lambda: th.join(JOIN_S + 5))
 657              rec['scheduler'] = {**sched, 'thread_alive': th.is_alive()}
 658              if sched.get('error') or sched.get('alive') or th.is_alive():
 659                  rec['errors'].append(f'scheduler: {rec["scheduler"]}')
 660          if m:
 661              m.close()
 662              rec['ticks'] = m.ticks
 663              for ev in m.events:
 664                  add({'kind': 'event', **{k: v for k, v in ev.items() if k != 'item'}})
 665          if watch:

 706  def pauses(rows, end_t):
 707      """(count, time to the first, total s): an interval runs from the intent to leave ACTIVE (picker forbidden,
 708      camera stop begins) to the successful re-entry into ACTIVE after the camera start (stage 'done'), or to end_t; a
 709      failed restart is no re-entry. Camera stop and start and the pause_start reading count as pause; the pause_end
 710      reading (picker allowed, camera on) as ACTIVE. The total counts mission time only: every interval is intersected
 711      with [0, end_t] (a restart completing after the deadline keeps its real time in its 'done' row)."""
 712      out, began = [], None
 713      for r in rows:
 714          if r['kind'] != 'heat':
 715              continue
 716          if r['stage'] == 'intent' and r['from'] == 'ACTIVE' and began is None:
 717              began = r['t']
 718          elif r['stage'] == 'done' and r['to'] == 'ACTIVE' and began is not None:
 719              out.append((began, r['t']))
 720              began = None
 721      if began is not None:
 722          out.append((began, max(began, end_t)))
 723      return len(out), (out[0][0] if out else None), round(sum(max(0.0, min(b, end_t) - max(a, 0.0)) for a, b in out), 3)

 726  def metrics(rec, rows, record, out):
 727      ev = [r for r in rows if r['kind'] == 'event']
 728      dec = [r for r in rows if r['kind'] == 'decision' and 'top' in r and not r.get('cancelled') and 'error' not in r]
 729      cyc = [r for r in rows if r['kind'] == 'cycle' and 'error' not in r]
 730      reads = rec['readings']
 731      end_t = rec.get('mission_end_s', 0)
 732      n, first, total = pauses(rows, end_t)
 733      fates = {s: {f: sum(e['fate'] == f for e in ev if e['source'] == s)
 734                   for f in ('served', 'dropped', 'cancelled', 'unserved', 'error')} for s in ('scripted', 'real')}
 735      for s in fates:
 736          fates[s]['offered'] = sum(e['source'] == s for e in ev)
 737      fates['real']['late_not_offered'] = rec.get('late_not_offered', 0)
 738      periods = [b['t'] - a['t'] for a, b in zip(cyc, cyc[1:]) if a['slot'] == b['slot']]
 739      skins = [c['skin'] for c in reads if c.get('skin') is not None]
 740      scripted = [r for r in dec if r['source'] == 'scripted']
 741      differ = sorted({r['id'] for r in scripted if r['top'] != record.get(r['id'])})
 742      start = next((c for c in reads if c['tag'] == 'start'), None)
 743      end = next((c for c in reads if c['tag'] == 'end'), None)
 744      return {
 745          'decisions_served': len(dec), 'events': fates,
 746          'latency_s': {s: stat([e['latency_s'] for e in ev if s in ('all', e['source']) and e['fate'] == 'served'])
 747                        for s in ('scripted', 'real', 'all')},
 748          'wait_s': stat([e.get('wait_s') for e in ev if e['fate'] == 'served']),
 749          'decision_wall_s': stat([r['wall_s'] for r in dec]),
 750          'ticks': rec.get('ticks'),
 751          'pauses': n, 'resumes': sum(r['kind'] == 'heat' and r['stage'] == 'done' and r['to'] == 'ACTIVE' for r in rows),
 752          'first_pause_s': first, 'pause_s': total, 'arm_s': round(end_t, 3),
 753          'active_share': round(1 - total / end_t, 3) if end_t else None,
 754          'skin': {'start': start and start.get('skin'), 'max_readings': max(skins) if skins else None,
 755                   'max_trace': trace_max(out / rec['heat_trace']) if rec.get('heat_trace') else None,
 756                   'end': end and end.get('skin')},
 757          'caps_min': {p: min([c['caps'][p] for c in reads if isinstance(c.get('caps', {}).get(p), int)], default=None)
 758                       for p in b4.POLICIES},
 759          'cycle_period_s': stat(periods), 'detect_ms': {z: stat([r['detect_ms'] for r in cyc if r['size'] == z], 1)
 760                                                        for z in (320, 640)},
 761          'mem_available_min_kb': min([c['avail_kb'] for c in reads if 'avail_kb' in c], default=None),
 762          'energy_indicative': b4.energy(start, end) if start and end else None,
 763          'repins': repin_summary(rec),
 764          'agreement': {'compared': len(scripted), 'agree': len(scripted) - sum(r['top'] != record.get(r['id'])
 765                                                                               for r in scripted), 'ids_differ': differ},
 766      }

 769  def repin_summary(rec):
 770      """Re-pins that changed threads or failed, per trigger and process; drifted scans per process; every CPU group
 771      (cpuset / cgroup) value seen per process across the scans (more than one value: Android moved it)."""
 772      samples = rec.get('watch', {}).get('samples', [])
 773      acted = {}
 774      for e in rec.get('repins', []):
 775          if e.get('threads') or not e['ok']:
 776              k = f'{e["trigger"]}/{e["process"]}'
 777              acted[k] = acted.get(k, 0) + 1
 778      drift = {}
 779      for x in samples:
 780          for p in x.get('drift', {}):
 781              drift[p] = drift.get(p, 0) + 1
 782      seen = {}
 783      for x in samples:
 784          for k, v in x.get('groups', {}).items():
 785              seen.setdefault(k, set()).add(v)
 786      return {'acted': acted, 'failed': sum(not e['ok'] for e in rec.get('repins', [])), 'drifted_scans': drift,
 787              'groups_seen': {k: sorted(v) for k, v in seen.items()}}

 315      def setUp(self):
 316          self.c = test_b4.FakeClock()
 317          self.saved = b5.clock, b5.pause, b4.cores_ok, main.read_frame
 318          b5.clock, b5.pause, b4.cores_ok = self.c, self.c.sleep, lambda: True

 320      def tearDown(self):
 321          b5.clock, b5.pause, b4.cores_ok, main.read_frame = self.saved

 323      def run_loop(self, plan, arm='B', work_s=120, status=(), persons=None, fail_start=False, battery=90, start_s=0.0,
 324                   read_s=0.0, hook=None, ready=None):
 325          t0 = self.c()
 326          heat = FakeHeat(self.c, [(t0 + a, x) for a, x in plan], [(t0 + a, s) for a, s in status])
 327          robot = FakeRobot(self.c, {t0 + a: b for a, b in (persons or {}).items()}, fail_start, start_s)
 328          main.read_frame = robot.read
 329          m = b5.Mission(arm, t0, work_s, ITEMS)
 330          robot.m = m
 331          rec, rows, oks = {'errors': [], 'camera_stops': [], 'readings': []}, [], []
 332          cam = {'on': True, 'slot': 1}
 333  
 334          def read(tag):
 335              rec['readings'].append({'tag': tag, 'camera': cam['on'], 't': m.rel(self.c()), 'ok': m.ok})
 336              self.c.sleep(read_s)  # a root reading takes time
 337              if hook:
 338                  hook(tag, m)
 339              if battery < b5.BATTERY_STOP_PCT:
 340                  rec['errors'].append('battery')
 341                  return False
 342              return True
 343          real_set_ok = m.set_ok
 344          m.set_ok = lambda ok: (oks.append((m.rel(self.c()), ok)), real_set_ok(ok))
 345          self.last_m = m
 346          b5.mission_loop(robot, heat, m, rec, rows.append, read, cam, ready or (lambda: None))
 347          return m, rec, rows, robot, heat, oks, cam

 629      def test_concurrent_repins_each_caller_gets_its_own_event(self):
 630          class HookLock:  # releases, then lets the mission thread re-pin before the watcher's add() returns
 631              def __init__(self):
 632                  self.lock, self.hook = threading.Lock(), None
 633  
 634              def __enter__(self):
 635                  self.lock.acquire()
 636  
 637              def __exit__(self, *exc):
 638                  self.lock.release()
 639                  hook, self.hook = self.hook, None
 640                  if hook:
 641                      t = threading.Thread(target=hook)
 642                      t.start()
 643                      t.join()
 644          rp = b5.Repinner({'server_pid': 4242})
 645          rp.lock, got = HookLock(), {}
 646          rp.lock.hook = lambda: got.__setitem__('camera', rp.server('camera_start'))
 647          hit = 'llama-server thread 11 Cpus_allowed_list:\t0-7'
 648          with unittest.mock.patch.object(b4, 'watch_check', lambda t: {'mono': 1.0, 'hits': [hit], 'vanished': 0}):
 649              x = b5.scan({'server_pid': 4242}, rp)  # the watcher
 650          self.assertEqual([(e['trigger'], e['process']) for e in x['repins']], [('watch', 'llama_server')])
 651          self.assertEqual(x['repins'][0]['threads'], [11, 13])  # the watcher's correction, not the later no-op
 652          self.assertEqual(got['camera']['trigger'], 'camera_start')
 653          self.assertEqual([e['trigger'] for e in rp.events], ['watch', 'camera_start'])
 654          self.assertIs(rp.events[0], x['repins'][0])

 707      def test_validity(self):
 708          ok = {'trigger': 'watch', 'process': 'llama_server', 'ok': True}
 709          bad = {**ok, 'ok': False, 'errors': {13: 'EPERM'}}
 710          # drift corrected by one re-pin: VALID, the event recorded
 711          rec = arm_record(watch=self.watch([[], ['llama_server'], [], ['detector'], []]), repins=[ok, ok])
 712          self.assertEqual(b5.arm_problems(rec, [CYC]), [])
 713          # the same process drifted in two consecutive scans: INVALID
 714          rec = arm_record(watch=self.watch([[], ['llama_server'], ['llama_server'], []]), repins=[ok, ok])
 715          self.assertTrue(any('two consecutive scans' in p for p in b5.arm_problems(rec, [CYC])))
 716          # different processes in consecutive scans: each corrected once, VALID
 717          rec = arm_record(watch=self.watch([['llama_server'], ['detector']]), repins=[ok, ok])
 718          self.assertEqual(b5.arm_problems(rec, [CYC]), [])
 719          # a failed re-pin (watch, arm start or camera start): INVALID
 720          for trig in ('watch', 'arm_start', 'camera_start'):
 721              rec = arm_record(watch=self.watch([[]]), repins=[{**bad, 'trigger': trig}])
 722              self.assertTrue(any('re-pin failed' in p for p in b5.arm_problems(rec, [CYC])), trig)
 723          rec = arm_record(repins=[bad])
 724          del rec['watch']
 725          self.assertTrue(any('re-pin failed' in p for p in b5.arm_problems(rec, [CYC])))

   3  Research only. With RobotCam + YOLO running (CAM1-MID, #136) and the deployed adaptive heat pause in force (37 °C
   4  pause / 35 °C resume, #135), how many B2 V3 picker decisions does the phone serve in 30 minutes, how fast after an
   5  event, how much time do heat pauses take, and does throttling change the picker's choices? Timings count only from

   9    imports `motors` without `--dry`, is not imported); `main.Robot(None)` has no motors (distance 999 cm, moves are
  10    sleeps). An arm refuses to start, and is INVALID, if `motors` or `serial` is in `sys.modules` at its start or end.
  11    No serial port, no ESP32, no MTP, no memory notes, no vision calls.

  13    (`b4.server_command(<run>, 'P')`: b11716, setup_q4 flags, `--slot-save-path <run>/slots`, Q8_0 projector at 70
  14    image tokens; `bc.PINS`); the 40 B2 TEST prompts (V3 FWD, `b2.preflight`), the common prefix sent once and slot 0
  15    saved (`b4.warm`); `heat_control.HeatControl(HeatMonitor())` started (its own 1 s / 5 s root readings: essential
  16    safety monitoring; trace in the run folder); `robot.start_camera(heat)`; start reading; B4's 30 s watcher.
  17  - **Mission loop** = `Robot.run_mission` motors-off: heat transitions exactly as `main.py` (picker forbidden, camera
  18    stopped and shown stopped, `heat.enter`, then the pause-start reading; resume: `start_camera(heat)`,
  19    `heat.enter('ACTIVE', since=before the start)`, picker allowed with a fresh SEVERE check, then the pause-end
  20    reading; a battery stop or an error in that reading forbids the picker at once and ends the arm); HOLD sleeps 1 s,
  21    PAUSE the move time; ACTIVE runs B4's camera cycle (new frame, SizePolicy, detect) then the move time. Picker
  22    allowed only while ACTIVE and Android status < SEVERE; a forbid cancels a running decision (checked before and
  23    after every HTTP request and before its result is accepted; a forbid followed by an allow still cancels). Heat
  24    END, a camera start/stop failure or an unusable frame ends the arm.
  25  - **Start barrier.** The scheduler thread starts only after the mission loop's first heat / SEVERE assessment has
  26    set the picker's permission, so no 30 s mark is consumed before it.
  27  - **Pause accounting.** Each heat transition logs an `intent` row when it begins and a `done` row when it completed.
  28    A pause runs from the intent to leave ACTIVE (picker forbidden, camera stop begins) to the `done` re-entry into
  29    ACTIVE (camera started); only that counts as a resume, a failed restart does not (the pause stays open to the arm
  30    end). Camera stop, the pause-start reading and camera start count as pause time; the pause-end reading counts as
  31    ACTIVE (camera on, picker allowed). Pause time counts mission time only (each pause clipped to [0, mission end]; a
  32    restart completing after the deadline keeps its real time in its `done` row). ACTIVE share = 1 − pause time /
  33    mission time.
  34  - **Events.** Scripted: the 40 B2 TEST items in id order, cycled, one every 10 s (180 per arm). Real: the most
  35    confident person's area bucket per ACTIVE cycle; appear / leave / bucket change → an event line in the B2 state
  36    format (mission M1, current activity exploring, memory none, all five actions; served, unscored). Pending queue of
  37    one: a newer event replaces an unserved one (dropped).
  38  - **Arms** (30 min of mission time each, order A then B): **A FIXED** at each 30 s mark, if allowed and idle, decide
  39    on the pending event; **B ADAPTIVE** as soon as an event is pending, the previous decision finished, the picker is
  40    allowed and the heat control's latest VIRTUAL-SKIN < 36.0 °C. A decision: slot 0 restored before every 5th, then
  41    `b2.score` unchanged (a real event's prompt is rendered first, inside its wall). A cancelled decision's event goes
  42    back to pending unless a newer one is waiting. The scheduler polls every 0.1 s (latency resolution).
  43  - **Deadline.** Nothing starts after it: the deadline is rechecked right before each camera cycle, so a transition
  44    (and its reading) that crosses it finishes but admits no cycle; the decision or camera cycle in flight finishes;
  45    overrun ≤ 15 s. A person change seen by a cycle admitted before the deadline that ends after it is not offered
  46    (counted `late_not_offered`).
  47  - **Readings** (`b4.reading`, per-PID memory checked): start (taken before the mission's t0: its relative time is
  48    negative), end, one at each heat-pause start (after the camera stop) and end (after the camera start). RobotCam
  49    memory required while the camera is on.

  52    finds drift, every llama-server thread is re-pinned to 4–7 (`os.sched_setaffinity` per thread) and the detector to
